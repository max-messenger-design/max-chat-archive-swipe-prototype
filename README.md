# HTML-прототип «Скрытый архив по свайпу»

Откройте `index.html` или `01-chat-list.html` в браузере. На компьютере прототип показывается в размере макета 360×800, а на телефонах и планшетах разворачивается на весь доступный экран без рамок. Используются локальные ассеты из Figma.

Сценарий:

1. Зажмите строку «Архив» примерно на 0,6 секунды — откроется `02-archive-actions.html`.
2. Нажмите «Скрыть» — откроется `03-archive-hidden.html` с короткой подсказкой о новом жесте.
3. На списке чатов проведите пальцем или курсором слева направо. Архив появляется из-под экрана и открывается после достаточного расстояния или быстрого свайпа. Короткий жест возвращает список на место.
4. В открытом свайпом архиве проведите влево, чтобы вернуться к чатам. Крестик слева запускает ту же обратную анимацию. Короткий обратный жест отменяется.
5. Для доступности сфокусируйте список чатов и нажмите клавишу `→`, чтобы открыть архив; в архиве нажмите `←` или `Escape`, чтобы вернуться.
6. В архиве нажмите кнопку с тремя точками — откроется `07-archive-menu.html`.
7. Выберите «Настройки архива» — откроется `08-archive-settings.html`. Переключатель «Показывать в списке чатов» возвращает или снова скрывает строку архива.
8. Нажмите таб «Настройки» — откроется `09-settings.html`. Строка «Архив» открывает архив, а кнопка «Назад» возвращает в настройки.

Для быстрой визуальной проверки каждое состояние также доступно отдельным HTML-файлом.
